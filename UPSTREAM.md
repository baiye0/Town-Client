# Source provenance

Town-Client starts from the current client and Portal source snapshot, including local development changes.

- Client: https://github.com/baiye0/loom-local, base commit `5d347107326fd754fafea1c1dc373a42986ff49f`.
- Heart Portal: https://github.com/baiye0/heart-portal, base commit `2dab52fc081d80a7bda9ce7735ab50c6cc6726ac`.

The `heart-portal/` directory is maintained directly in this repository, so a normal clone includes the matching engine source. Original license and copyright notices are retained in the project README, `heart-portal/LICENSE`, and `resources/HEART-PORTAL-LICENSE`.

The `hardening/` directory contains historical design and verification notes from the source workspace; old local paths and submodule references there describe that original workspace.
